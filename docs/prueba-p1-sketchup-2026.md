# P1.2 — Prueba necesaria en SketchUp 2026 Windows

**Pendiente.** La nube ejecuta dobles de API y navegador, no SketchUp. No se marca la integración OpenCutList terminada. Usar una **copia** de `CA AmSurrbac (1).skp`; mantener el original y los complementos actuales.

1. Instalar `PlanosSanto-0.6.5.rbz` desde Ventana → Administrador de extensiones → Instalar extensión. Guardar cualquier trabajo pendiente y **cerrar todas las ventanas de SketchUp** antes de volver a abrir. Verificar versión 0.6.5 habilitada. No descomprimir ni instalar el ZIP de desarrollo. El editor anterior permanece en Extensiones → Planos Santo → Planos Santo.
2. Abrir la copia. Si ya está instalado OpenCutList oficial, conservarlo; no es obligatorio para este diagnóstico. Anotar su versión/build y comprobar que su menú original siga abriendo.
3. Extensiones → Planos Santo → **Diagnóstico de integración (solo lectura)…**. Elegir un nombre nuevo para el JSON. No reemplaza informes previos ni modifica/guarda el SKP. Esperar confirmación; si informa recorrido incompleto, conservar ese JSON para revisar las incidencias.
4. Elegir un mueble padre cuya jerarquía se conozca. Comprobar que todos sus grupos/componentes aparecen con sus rutas y que dos instancias de una definición compartida tienen rutas distintas. Repetir seleccionando una pieza dentro de un grupo abierto; comprobar `selection_paths` incluye sus ancestros. Un grupo intermedio puede figurar como contenedor sin que sea otro mueble: aún debe confirmarse la raíz real.
5. Contrastar **cinco piezas**: una lateral, un estante, una rotada, una repetida/anidada y una con material en cara o escala (si existe). Registrar ruta/PID, nombre, dimensiones XYZ locales medidas en mm, dimensiones del informe, rotación/escala/espejo, material de instancia y frente/dorso. Si no hay alguno de estos casos en el modelo, indicarlo y usar un modelo sintético separado, sin modificar el original. No comparar `axis_lengths_mm` con una caja mundial rotada; no son largo/base para el proveedor.
6. Indicar qué lado es el frente del mueble y qué caras tienen cantos reales. Si no se puede establecer, registrar **incierto**; no aceptar el pedido ni inventar orientación. En geometría con agujeros comprobar que se conservaron loops/triángulos.
7. Antes/después del diagnóstico verificar nombres, transformaciones, selección y estado de modificación del documento. No debe aparecer operación nueva de Planos Santo en Deshacer ni requerir guardar el SKP por diagnosticar. Repetir cancelando y eligiendo un archivo ya existente: no debe producir cambios ni sobreescribirlo.
8. Regresión rápida: abrir editor, generar frente/atrás, rotar/guardar cámaras, editar un nombre junto al dibujo, agrupar componentes iguales, mover/ocultar cota/ID, guardar/cerrar y exportar PDF después de guardar. Son operaciones de edición distintas del diagnóstico, por eso hacerlas sobre la copia. Confirmar reapertura del SKP, Undo e impresión A3.

## Devolver para continuar

Adjuntar el **JSON de diagnóstico**, versión de SketchUp/OpenCutList, errores de Consola Ruby si los hubiera y una tabla con las cinco comprobaciones (`ruta/PID | medida real mm XYZ | informe mm XYZ | material/frente/canto | coincide/observación`). El archivo contiene nombres y geometría privados; compartirlo deliberadamente, no publicarlo. No basta decir que el botón se abrió. Con estos datos se resolverá P1.2 y se podrá decidir el adaptador de materiales/cantos, sin asumir que 1523 definiciones son 1523 tablones.

No se han instalado extensiones en Windows desde esta nube ni validado esa tabla. Las aceptaciones manuales anteriores permanecen pendientes.
